BASELINE MODEL

Linear Regression

A simple baseline regression model used for comparison.

Linear Regression Equation

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

The prediction is calculated as a weighted sum of input features plus an intercept.

Mean Absolute Error

MAE = (1/n) Σ |yᵢ − ŷᵢ|

Measures the average absolute prediction error.

Root Mean Squared Error

RMSE = √[(1/n) Σ(yᵢ − ŷᵢ)²]

Penalizes larger errors more strongly.

R² Score

R² = 1 − SSE/SST

Measures how much variation in PM2.5 is explained by the model.

ENSEMBLE LEARNING

Random Forest Regression

Random Forest combines multiple decision trees to improve prediction accuracy and reduce overfitting.

How Random Forest Works

Random Forest creates many decision trees using different random samples of the training data. Each tree predicts a PM2.5 value, and the final prediction is the average of all tree predictions.

Final Prediction = Average of all Tree Predictions

BOOSTING ALGORITHM

XGBoost Regression

XGBoost builds trees sequentially, where each new tree tries to correct the errors made by previous trees.

How XGBoost Works

XGBoost uses gradient boosting. Trees are added one after another, and each tree improves the overall model by reducing the previous prediction errors.

New Model = Previous Model + Learning Rate × New Tree

MAE

MAE = Σ|Actual − Predicted| / n

Lower MAE means predictions are closer to actual values on average.

RMSE = √(1/n Σ(y − ŷ)²)

Lower RMSE means fewer large prediction errors.

Higher R² means the model explains more variation.
